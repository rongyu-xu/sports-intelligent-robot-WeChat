# 体育智能机器人微信小程序

## 项目简介
这是一个体育智能机器人微信小程序，包含场馆展示、课程管理、成长记录等功能。

## 如何运行

1. 确保您已经安装了微信开发者工具
2. 打开微信开发者工具，选择"导入项目"
3. 选择本项目的根目录
4. 填写您的AppID（如果没有，可以选择"测试号"）
5. 点击"导入"按钮
6. 导入成功后，您可以在微信开发者工具中预览和测试这个小程序

## 主要功能

- 地图页面：展示附近的体育场馆，支持点击进入场馆详情
- 场馆详情：展示场馆信息、教练力量、智能设备和学员评价
- 课程页面：展示可用的体育课程
- 成长页面：记录用户的运动成长数据
- 个人中心：用户信息管理

## 注意事项

- 本项目使用微信小程序原生开发，不需要使用npm或其他包管理器
- 如果您遇到页面跳转问题，请确保所有页面都在app.json中正确注册
- 如果您遇到资源加载问题，请确保图片资源路径正确
